# @antkit/styles

Design tokens for [@antkit/react](https://github.com/zocheck/antkit). One CSS
file: colour, radius and font tokens, plus the `dark` variant.

```css
@import 'tailwindcss';
@import '@antkit/styles';
```

Dark mode is the `dark` class on `<html>`. Override any token by redeclaring
it after the import.
