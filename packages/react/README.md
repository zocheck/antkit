# @antkit/react

Ant Design-shaped React components on Radix and Tailwind v4.

```bash
pnpm add @antkit/react @antkit/styles
```

```css
@import 'tailwindcss';
@import '@antkit/styles';
@source '../node_modules/@antkit/react/src';
```

```tsx
import { Button } from '@antkit/react';

<Button>Lưu</Button>;
```

Full docs: [github.com/zocheck/antkit](https://github.com/zocheck/antkit)
