# Progress

A bar or ring, with success and error states.

```tsx
import { Progress } from '@antkit/react';
```

How far along something is.

```tsx
<Progress percent={64} />
<Progress type="circle" percent={100} status="success" />
```

## Props

- `type`
- `size`
- `diameter`
- `strokeWidth`
