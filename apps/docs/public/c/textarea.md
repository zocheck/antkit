# Textarea

A multi-line field that grows with its content and counts characters.

```tsx
import { Textarea } from '@antkit/react';
```

A multi-line text field.

```tsx
<Textarea placeholder="Notes" autoSize={{ minRows: 2, maxRows: 6 }} />
<Textarea maxLength={200} showCount />
```

## Props

- `autoSize`
- `showCount`
- `wrapperClassName`
